- Single text sentiment analysis

An intelligent sentiment analysis web application built using **Streamlit**, **LangChain**, and **LLaMA 3.2 (via Ollama)**. The application analyzes textual data and classifies it into **Positive**, **Negative**, **Neutral**, or **Mixed** sentiments while providing confidence scores for predictions.

The system also includes an interactive AI chatbot, batch sentiment analysis capabilities, and visual insights through word cloud generation.

## 🌟 Features

* 🔍 **Single Text Sentiment Analysis**

  * Analyze sentiment for individual text inputs.
  * Returns sentiment label along with confidence score.

* 📂 **Batch Sentiment Analysis**

  * Upload `.csv` or `.txt` files for bulk sentiment analysis.
  * Supports confidence-based filtering of results.

* 💬 **Interactive AI Chatbot**

  * Conversational chatbot powered by **LLaMA 3.2**.
  * Maintains session-based conversation history.

* ☁️ **Word Cloud Visualization**

  * Generates word clouds to highlight frequently occurring words.

* 🎨 **Modern User Interface**

  * Attractive and responsive UI built with custom CSS in Streamlit.

* 🔄 **Automatic File Encoding Detection**

  * Detects and handles different file encodings using **Chardet**.

## 🛠️ Technologies Used

* **Programming Language:** Python
* **Frontend & UI:** Streamlit, HTML, CSS
* **LLM Framework:** LangChain
* **Large Language Model:** Ollama (LLaMA 3.2)
* **Data Processing:** Pandas
* **Visualization:** Matplotlib, WordCloud
* **Utilities:** Regex, Chardet
